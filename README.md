QuizQuest – The Ultimate Mixed Quiz Game
ABOUT

QuizQuest is a fun, interactive quiz game developed using the C programming language

Players can test their knowledge across different categories

CATEGORIES
- General Knowledge
- Science
- Technology
- Entertainment

FEATURES
- Enter the player's name
- Select one or multiple categories
- Answer multiple-choice questions
- Get immediate feedback on answers
- View the correct answer when an answer is wrong
- Track the total score
- Display the final results

CURRENT QUESTION LIMIT
5 questions per category (initial version)

TECHNOLOGIES USED
- C Programming
- Git
- GitHub

PROJECT STATUS
Planning and development in progress
